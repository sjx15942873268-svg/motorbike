# 视觉验收报告

> 验收对象：`qa/shots/` 14 张截图（1440×900，mobile 390×844），对照 `reference.png` 与 `docs/SPEC.md`。
> 环境说明：swiftshader 软渲染 ~2fps，补间被时间稀释约 8 倍；动画中间态不算缺陷。控制台日志 14 张全部只有 `[rider01] ready`，0 报错。

## 一、总分

外观总分：**6.0 / 10**（轮廓 6、配色 6、标志性部件 7、比例 5、光影质感 6）

## 二、五维评述

**轮廓 6/10**：整体可读出 Vespa 式复古踏板（大前护板、鼓包侧裙、后驮箱），但后轮被侧裙完全吞掉（`inspect_side` / `sound` / `solo_model`），整车像「没轮子的玩具」；前挡泥板过大下探，进一步破坏侧面剪影。

**配色 6/10**：色板本身正确（黄身、黑箱黄边、镀铬货架、银色轮毂、黑座垫）。但受光面被美团黄轮廓光 + bloom 洗成奶油白（实测车身受光面 #F1DD94，偏离 #FBC405），黑色件在暖光下泛棕，整体偏「塑料玩具感」。

**标志性部件 7/10**：外卖箱、黄色袋鼠标识、「美团外卖 / 送啥都快」字样、镀铬后货架、鼓包侧裙贴花、前护板、圆大灯、前挡泥板、尾灯与牌照、黑座垫均在；扣分在后轮连银色轮毂盖一起不可见（参考图中是标志元素），且控制器裸露在脚踏板下方。

**比例 5/10**：轴距、车长、座高、箱底高等骨架比例成立，但后轮被车身封死、前挡泥板包角过大且几乎贴地、前护板过于肥厚、车把偏小，侧面「轮小身大」的观感与参考图差距明显。

**光影质感 6/10**：夜间电影感、暖主光 + 黄色轮廓光、展台黄圈与泛光都到位；但大灯在关灯状态下仍被环境反射打成白球，受光面过曝，轮胎与背景死黑，画面整体单色偏黄。
