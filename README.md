# THE RIDER No. 01 — 一台会跑单的外卖电动车

一个纯前端、零构建的 3D 交互网页：夜色街道里的一台美团外卖电动车，可以骑、可以拆、可以看穿、可以听它响。

参考图见 `reference.png`，冻结契约见 `docs/SPEC.md`。

## 运行

线上地址：<https://sjx15942873268-svg.github.io/motorbike/>

本地跑需要一个静态文件服务器（ES Modules 不能用 `file://` 直接打开）：

```bash
cd motorbike
python3 -m http.server 8080
```

然后浏览器打开 <http://localhost:8080/>。

- three.js 0.170 通过 importmap 从 jsDelivr CDN 加载，**首次打开需要联网**。
- 首次点击或按键后才会解锁音频（浏览器自动播放限制），界面上会提示「点击任意处开启声音」。
- 没有任何 npm 依赖参与运行；`node_modules/playwright` 只用于验收截图。

## 键位

| 按键 | 功能 |
|---|---|
| W / ↑ | 加速（松开后滑行减速，上限 25 km/h） |
| S / ↓ | 刹车 |
| A D / ← → | 转向 |
| Q / E | 左 / 右转向灯 |
| H | 喇叭 |
| L | 大灯 |
| F | 开合外卖箱 |
| X | 剖视 |
| 1 ~ 4 | 切换视角（骑行 / 电驱 / 检视 / 声音） |

焦点在输入控件上时快捷键不生效；空格和方向键会 `preventDefault`。移动端（≤720px）显示油门 / 刹车触控按钮。

## 四个视角

| 视角 | 看什么 |
|---|---|
| 骑行 ride | 追尾跟随。道路向后流动、路灯循环掠过，速度表、跑单进度条实时变化 |
| 电驱 drive | 正侧面近景 + X 光：外壳半透明，电池青电芯、控制器、轮毂电机、线束发光，线束上的电流随油门流动 |
| 检视 inspect | 自由旋转/缩放（限制俯仰与距离），展台地面，18 个零件热点标签，点击零件弹信息卡 |
| 声音 sound | 右前方 3/4 固定机位，底部波形与频谱实时绘制，发声零件同步闪光 |

## 玩法

- **拆解**：左下角 CONTROL DESK 的滑块从 0 拖到 100%，18 个零件按外层先动的顺序分离；拖回 0 精确复位。检视视角下相机自动拉远保证全部零件在画面内。
- **剖视**：只剖外壳（`z > 0` 半剖），内部车架和电池保持完整，可以看到外壳内侧。
- **跑单**：右下订单卡片给出配送距离，骑到里程达标后「已送达」徽标弹出，单数 +1 并自动派下一单。
- **导览**：底部卡片 5 步（车身 → 电池组 → 轮毂电机 → 控制器 → 外卖箱），每步高亮对应零件并自动运镜。
- **记录**：里程、单数、骑行时长每 5 秒和每次送达写入 `localStorage`（键 `rider01.log`），刷新后保留。
- **导出海报**：把当前 3D 画面渲到 1080×1350 的 2D 画布，叠加标题与今日数据，下载为 `rider-01.png`。

## 技术要点

- three.js 0.170，ES Modules + importmap，无打包器、无构建步骤。
- 后期链顺序：RenderPass → OutlinePass → UnrealBloomPass → **OutputPass（必须最后）**。
- 坐标系：米，+Y 向上，车头朝 +X，**+Z 为车辆左侧**；车轮绕 Z 旋转。
- 车身黄取实测参考图的 `#FBC405`。
- 全部音效用 Web Audio 实时合成，不加载任何音频文件。
- 程序化建模：143 个 mesh / 约 5.3 万三角面，远低于 30 万上限。

## 已知问题

1. **需要联网**：three.js 0.170 经 importmap 从 jsDelivr CDN 加载，离线或 CDN 不可达时页面起不来。
2. **音频要交互后才出声**：浏览器自动播放策略，首次点击或按键才解锁；解锁前声音视角只画待机波形。
3. **无 GPU 环境下帧率很低**：验收用的 swiftshader 软渲染约 2fps，此时补间动画因 `dt` 钳制（0.05s）被时间稀释，截图流程里速度表可能达不到满速——真机 GPU 不受影响。
4. **移动端是增强支持**：≤720px 有油门 / 刹车触控按钮、控制台收进底部抽屉、窄屏相机自动拉远；未做双指缩放等完整触摸手势。
5. **检视视角标签在零件密集处仍偏挤**：已加屏幕空间碰撞避让（18 个标签不再互相遮挡），但线束 / 电池组 / 控制器附近标签离零件较远。
6. **DOCX 导出等附录 B 扩展未实现**（PLAN 列为 P2「可以有」）。
